# Bioinformatics Research Assistant at the Parfrey Lab, University of British Columbia (May 2026 - Present)

This repository contains scripts from my analyses at the Parfrey lab. 

Thus far, I have worked with 16S rRNA sequencing data from seagrass and kelp samples, and am currently beginning metagenomic fucus (algal) analysis.

My 16S analysis includes:
- Filtering and rarefying phyloseq objects, using library size and ASV prevalence and abundance as QC metrics
- Alpha (richness, evenness, Shannon's index) and beta (bray-curtis, jaccard, NMDS) diversity metrics, including visualization and statistical testing (ANOVA, Kruskal-Wallis, Welch's test, PERMANOVA, and accompanying post-hoc tests)
- Taxaplots, presence/absence and differential abundance metrics (DESeq2, ANCOMBC) visualized through volcano plots
- Comparing growth statistics across treatments and looking for correlations with various covariates
- Running PICRUSt2 with a Bash script and performing downstream analyses, including differential abundance and gene set enrichment analysis with GSEA
